Contexte du projet
Je m'appelle Malik Ibo, développeur Java junior, formé chez Dawan Montpellier. Je construis SpringHotel, une application full-stack de réservation hôtelière ciblant Montpellier, avec une intégration complète du logiciel Pastell de Libriciel SCOP (bus d'orchestration pour le secteur public).
Le projet est public, déployé en production, et a déjà été présenté en deux versions à Libriciel. Ma candidature au poste DevRel a été refusée le 20 mai 2026 pour "trop tôt dans le parcours". J'ai envoyé la V2 le 21 mai par démarche personnelle, en assumant le refus, pour terminer ce que j'avais commencé.
Maintenant, je veux continuer à faire évoluer le projet pour qu'il devienne un portfolio présentable à n'importe quel recruteur Java (ESN, éditeur, startup, secteur public), pas seulement Libriciel.

INFRASTRUCTURE (depuis back-end/)
bash# Démarrer PostgreSQL + Keycloak
./run-local.sh infra

# Surveiller les logs Keycloak jusqu'au message "Started Keycloak"
docker compose logs -f keycloak

# Arrêter les conteneurs (données conservées)
./run-local.sh infra-stop

# Reset complet : supprime les volumes, le realm est réimporté au prochain démarrage
./run-local.sh infra-reset

# Reset Keycloak uniquement (sans toucher à PostgreSQL)
docker compose stop keycloak
docker volume rm back-end_hotel_keycloak_data
docker compose up -d keycloak

# Vérifier que les conteneurs tournent
docker compose ps

# Vérifier que Keycloak est prêt (doit retourner du JSON)
curl http://localhost:8180/realms/springhotel

# Vérifier le document de découverte OIDC complet
curl http://localhost:8180/realms/springhotel/.well-known/openid-configuration | jq .

curl -s -X POST http://localhost:8080/api/v1/login \
  -H "Content-Type: application/json" \
  -d '{"email":"test@test.com","password":"test123"}' | jq .

# Récupérer un token Keycloak pour admin-demo
curl -s -X POST \
  "http://localhost:8180/realms/springhotel/protocol/openid-connect/token" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "grant_type=password&client_id=springhotel-frontend&username=admin-demo&password=Admin1234!&scope=openid pastell-admin" | jq .

# Tester un endpoint protégé avec un token Keycloak (en une seule commande)
curl -s "http://localhost:8080/api/admin/pastell/status" \
  -H "Authorization: Bearer $(curl -s -X POST \
    'http://localhost:8180/realms/springhotel/protocol/openid-connect/token' \
    -H 'Content-Type: application/x-www-form-urlencoded' \
    -d 'grant_type=password&client_id=springhotel-frontend&username=admin-demo&password=Admin1234!&scope=openid pastell-admin' \
  | jq -r '.access_token')" | jq .

# Tester /api/me avec un token Keycloak
curl -s "http://localhost:8080/api/me" \
  -H "Authorization: Bearer $(curl -s -X POST \
    'http://localhost:8180/realms/springhotel/protocol/openid-connect/token' \
    -H 'Content-Type: application/x-www-form-urlencoded' \
    -d 'grant_type=password&client_id=springhotel-frontend&username=admin-demo&password=Admin1234!&scope=openid' \
  | jq -r '.access_token')" | jq .

# Vérifier qu'un endpoint sans token retourne 401
curl -s http://localhost:8080/api/admin/pastell/status | jq .

# Lister les hôtels (endpoint public)
