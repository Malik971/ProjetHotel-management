Contexte du projet
Je m'appelle Malik Ibo, développeur Java junior, formé chez Dawan Montpellier. Je construis SpringHotel, une application full-stack de réservation hôtelière ciblant Montpellier, avec une intégration complète du logiciel Pastell de Libriciel SCOP (bus d'orchestration pour le secteur public).
Le projet est public, déployé en production, et a déjà été présenté en deux versions à Libriciel. Ma candidature au poste DevRel a été refusée le 20 mai 2026 pour "trop tôt dans le parcours". J'ai envoyé la V2 le 21 mai par démarche personnelle, en assumant le refus, pour terminer ce que j'avais commencé.
Maintenant, je veux continuer à faire évoluer le projet pour qu'il devienne un portfolio présentable à n'importe quel recruteur Java (ESN, éditeur, startup, secteur public), pas seulement Libriciel.

tentatives (pas retryCount)
derniereErreur (pas errorMessage)
